# Mohamed Besghaier Portfolio

Personal portfolio built with React and Vite. The site is designed to present a focused profile around web development, cybersecurity, and technical problem solving without adding unnecessary complexity.

## Stack

- React 19
- Vite
- CSS
- ESLint

## Sections

- Hero introduction with clear positioning
- About section focused on approach and learning path
- Project case studies
- Contact section with direct links

## Local Development

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal to view the site.

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Notes

- The portfolio is intentionally a single-page application.
- Content and projects are still evolving as new work is added.
